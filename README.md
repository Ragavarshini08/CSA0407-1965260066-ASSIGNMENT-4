## 1. Assignment Overview

This assignment focuses on understanding and implementing important storage management concepts in Operating Systems. It explores file-system design, file-allocation methods, modern file systems, disk scheduling algorithms, distributed storage and storage optimisation.

The assignment combines theoretical analysis with practical C programming to understand how operating systems manage files, allocate storage, schedule disk operations and improve overall system performance.

### Objectives

- Understand file-system organisation and management.
- Analyse different file-allocation techniques.
- Compare modern file systems and their features.
- Implement and evaluate disk scheduling algorithms.
- Understand distributed and cloud-based storage.
- Design efficient storage solutions for real-world applications.

---

## 2. Assignment Summary

### Task 01 – File-System Design Review

Analysed the limitations of flat directory structures and proposed a hierarchical file-system design for managing student records. The solution includes organised directories, file-naming conventions, access permissions, security, backup and recovery mechanisms.

### Task 02 – File-Allocation Methods

Studied and compared contiguous, linked and indexed file-allocation methods. Calculated storage requirements and explored inode-based allocation and free-space management. Implemented a C program to demonstrate file-allocation operations.

### Task 03 – Modern File Systems

Compared modern file systems such as FAT32, NTFS, ext4, XFS, Btrfs, ZFS and APFS. Analysed their features, performance, reliability, journaling, snapshots and data-integrity mechanisms.

### Task 04 – Disk Scheduling Algorithms

Studied and implemented FCFS, SSTF, SCAN, C-SCAN, LOOK and C-LOOK disk scheduling algorithms. Compared their performance based on disk-head movement and analysed fairness, efficiency and starvation.

### Task 05 – Distributed and Cloud-Based Storage

Explored distributed storage technologies such as NFS, HDFS, Ceph and cloud object storage. Analysed replication, consistency, scalability, reliability and device-management techniques. Proposed a suitable storage solution for large-scale data management.

### Task 06 – Storage Design for a Video-Streaming Start-up

Designed a hybrid storage architecture for a video-streaming application using SSDs, HDDs, cloud storage and caching techniques. Analysed storage requirements, access patterns and performance. Implemented a C program to simulate HDD-based and hybrid storage using an LRU cache.
